# Tasaki Shosaku — Reference Site / 田崎昭作 参考サイト

Source files for **https://ttakt.github.io/tasaki-shosaku/**, a reference site on the Japanese painter Tasaki Shosaku (田崎昭作, b. 1929): biography, exhibition history, and works catalog, in English and Japanese.

洋画家・田崎昭作（1929年生まれ）の経歴・展覧会歴・作品目録をまとめた参考サイト（英語・日本語）のソースファイルです。

## Contents / 構成

| Path | Page |
|---|---|
| `index.html` / `ja/index.html` | Home / トップ |
| `biography.html` / `ja/biography.html` | Biography & chronology / 経歴年表 |
| `works.html` / `ja/works.html` | Works catalog / 作品目録 |
| `assets/` | Icons, share images, and reference images of works / アイコン・共有画像・作品の参考画像 |

The site is plain HTML and CSS with no build step.

## Sources / 出典

Content is based mainly on exhibition catalogs published between 1988 and 2002, checked against independent institutions and publications where possible.

掲載内容は主に1988〜2002年に発行された展覧会図録に基づき、可能な範囲で独立した機関・文献と照合しています。
